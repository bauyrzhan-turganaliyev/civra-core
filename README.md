# Civra Core

Browser-based MMO prototype (distributed programming course project).

# Additional documents
- REPORT.md
- TESTS.md

## Requirements
- Docker Desktop (with Docker Compose v2)
- Make

## Run
make up
open http://localhost:8080

## Stop
make down

## Reset database (clean state)
make reset
